# PDF Editor

ブラウザだけで PDF を直す。もともとの文字の書き換えと追加、矩形塗り、ハイライト、枠線、手書き、画像の挿入ができる。ページの回転・削除・並べ替え・結合もできる。ファイルはサーバへ送られない。

- **Web:** https://symmr.github.io/pdf-editor/
- **GitHub:** https://github.com/symmr/pdf-editor/

画面下部にバージョン（例: `v1.0.0`）が表示されます。

リポジトリ構成: `docs/index.html`（UI）+ `docs/app.js` + `docs/pdf-text.js`（文字の抽出）+ `docs/pdf-rewrite.js`（描画命令からの削除）+ `docs/version.json`。

## 使い方

1. 上記 Web URL を Chrome または Edge で開く
2. PDF をドロップするか「PDF を開く」で開く
3. ツールを選んでページ上で操作する
4. 「PDF をダウンロード」で `元の名前_edited.pdf` を保存する

| ツール | キー | 操作 |
| --- | --- | --- |
| 選択 | V | クリックで選択、ドラッグで移動、右下の四角でサイズ変更（テキストは幅が変わって折り返す）。テキストはダブルクリックで再編集 |
| 文字を編集 | E | PDF の文字のまとまりが点線で囲まれる。クリックすると元の文字が入った入力欄になり、書き換えられる |
| テキスト | T | クリックした位置に入力。Enter で改行、Esc か枠の外をクリックで確定。書体はツールバーで選ぶ |
| 矩形塗り | F | ドラッグした範囲を選んだ色（初期値は白）で塗る。画像の中の文字を隠して上から書き直すときに使う |
| ハイライト | H | ドラッグした範囲に半透明の色を重ねる（色はほかのツールと別に覚える） |
| 枠線 | R | ドラッグした範囲を線で囲む |
| ペン | P | 手書き |
| 画像 | – | PNG / JPEG / WebP / GIF を挿入（PNG と JPEG 以外は PNG に変換） |

- 「文字を編集」で書き換えた文字は、ほかのテキストと同じく移動・幅の変更・色や太字の変更ができる。Delete で消すと元の文字に戻る。中身を空にして確定すると元の文字を消したことになる
- 「文字を編集」は元の揃え（左・中央・右）を引き継ぐ。複数行は各行の位置から、1行は余白や位置から推定する。ツールバーの左・中・右で変えられる
- 選択中の書き込みは Delete で消える。色・文字サイズ・線の太さを変えると選択中の書き込みに反映される
- 元に戻す / やり直す: Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y）
- ページ移動: ◀ ▶、← →、PageUp / PageDown
- サムネイルはドラッグで並べ替え、回転ボタンで回転、削除ボタンで削除する
- 「PDF を後ろに追加」か、編集中の画面へのドロップで別の PDF を末尾に結合する

## 文字の書き換え

PDF にはテキストボックスや段落の情報がない。中身は「このフォントで、この座標に、この文字列を描く」という命令の並びである。次の手順で書き換える。

1. pdf.js で文字の位置を取り出し、同じ行に並ぶ文字を行に、行間がそろって縦に続く行を段落（ブロック）にまとめる。これを点線の枠で示す
2. クリックしたブロックを、同じ位置・サイズ・色・太さ・書体のテキストに置き換える。書体はブロックに使われているフォントの名前（Meiryo UI、YuGothic-Regular など）を、このパソコンに入っているフォントと照合して決める。照合には「インストール済みフォントの読み取り」の許可が要る。Chrome と Edge など Chromium 系だけが対応し、Safari と Firefox では使えない。名前で決まらないときはページのほかの文字のフォント、それでも決まらないときは pdf.js が選ぶ代替書体に合わせる。2行以上の段落は元の幅で折り返す。色はページの描画命令から読み、背景との差が小さいときは表示中のページから拾う
3. 保存時は、ページの描画命令から元の文字列を取り除いてから新しい文字を書き込む。後ろに続く文字の位置は変わらない。コピーや検索でも元の文字は出てこない。取り除けなかった文字（画像の中の文字など）は背景色で覆う。画面のプレビューも同じ処理で文字を取り除いたページを描画する。ポインタをブロックの上に置くと、そのページを先に作っておく。出来上がるまでの間と、取り除けない文字だけ、背景色の矩形で覆って見せる。文字を変えずに編集をやめると、元のページを描き直す

抽出は `docs/pdf-text.js`、削除は `docs/pdf-rewrite.js` が行う。

## 保存

- 表示は [pdf.js](https://mozilla.github.io/pdf.js/)、書き出しは [@cantoo/pdf-lib](https://github.com/cantoo-scribe/pdf-lib) と [@cantoo/fontkit](https://github.com/cantoo-scribe/fontkit)。どれも jsDelivr から読み込む
- 保存は 1つ目の PDF をそのまま書き換える。フォームの入力欄、しおり、ページ間のリンク、文書情報（タイトルなど）が残る。後ろに追加した PDF はページだけを取り込む
- 保存した PDF には、どこからも参照されなくなったオブジェクトを入れない。削除したページの中身や、書き換える前の描画命令（元の文字）はファイルに残らない
- 書き込みは PDF のユーザー座標で持つ。ページを回転・拡大しても位置がずれず、保存時にそのままページの内容として描き込む（PDF の注釈オブジェクトではない）
- インストール済みフォントが使えないときは、Noto Sans JP（ゴシック）か Noto Serif JP（明朝）の TrueType で書き、使った文字だけをサブセット埋め込みする。フォント（1書体・1太さあたり 5〜8 MB）は、その書体のテキストを含む PDF を初めて保存するときに一度だけ取得する

## 制限

- **矩形塗りは見た目を隠すだけ。** 下の文字や画像は PDF に残り、コピーや抽出で読める。機密情報の墨消しには使わないこと
- 書き換えた文字は、元のフォントと同じ名前のフォントがこのパソコンに入っていれば、それで書く（Meiryo UI なら Meiryo UI のまま）。元の PDF のフォントは使われている文字しか入っていないことが多いため、PDF 内のものではなくインストール済みのものを使う
- 許可がない、フォントが見つからない、TrueType でない（OpenType CFF）、埋め込みが禁止されている、新しい文字がフォントにない、のいずれかのときは Noto Sans JP か Noto Serif JP で書く。ゴシックか明朝かは合わせるが、書体そのものは少し変わる
- 文字数が変わっても、周りの文章は詰まったり押し出されたりしない。長くなった段落は下に伸びるので、重なる場合は幅を広げるか文字を小さくする
- スキャンした PDF（文字が画像になっているもの）は「文字を編集」では書き換えられない。PowerPoint の PDF 書き出しで「フォントを埋め込めない場合はテキストをビットマップに変換」が働いたもの（Noto Sans JP の可変フォントなど）も同じ。隠し文字は読まない。書き出し側でフォントを変える（Yu Gothic など）。矩形塗りとテキストで上書きする
- 縦書きや斜めの文字はブロックとして拾わない
- 開くときにパスワードが要る PDF は開けない。パスワードなしで開けて印刷・編集だけを制限している PDF は編集でき、保存すると暗号化が外れて制限もなくなる
- 後ろに追加した PDF のフォームの入力欄やしおりは引き継がれない。削除したページを指すしおりやリンクは、飛び先のないものとして残る

## 開発

ビルドは不要。`file://` で直接開くと pdf.js の読み込みが CORS で止まるので、ローカルサーバを使う。

```sh
python3 -m http.server 8000 --directory docs
# http://localhost:8000/ を開く
```
