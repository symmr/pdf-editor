# PDF Editor

ブラウザだけで PDF を修正するツール。PDF にもともとある文字の書き換え、文字の追加、白塗り、ハイライト、枠線、手書き、画像（署名など）の挿入と、ページの回転・削除・並べ替え・結合ができる。ファイルはサーバへ送られない。

UI は [Translation Supporter](https://github.com/symmr/ppt-translation-supporter) と同じ配色・部品で作っている。

## 起動

ビルドは不要。静的ファイルとして配信すれば動く（`file://` で直接開くと pdf.js の読み込みが CORS で止まるので、ローカルサーバを使う）。

```sh
cd pdf-editor
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

GitHub Pages（リポジトリのルートを公開）などにそのまま置いても動く。

## 使い方

1. PDF をドロップするか「ファイルを選択」で開く
2. ツールを選んでページ上で操作する
3. 「PDF をダウンロード」で `元の名前_edited.pdf` を保存する

| ツール | キー | 操作 |
| --- | --- | --- |
| 選択 | V | クリックで選択、ドラッグで移動、右下の四角でサイズ変更（テキストは幅が変わって折り返す）、テキストはダブルクリックで再編集 |
| 文字を編集 | E | PDF の文字のまとまりが点線で囲まれる。クリックすると元の文字が入った入力欄になり、書き換えられる |
| テキスト | T | クリックした位置に入力。Enter で改行、Esc か枠の外をクリックで確定 |
| 白塗り | W | ドラッグした範囲を白で塗る。元の文字を消して上から書き直すときに使う |
| ハイライト | H | ドラッグした範囲に半透明の色を重ねる（色はほかのツールと別に覚える） |
| 枠線 | R | ドラッグした範囲を線で囲む |
| ペン | P | 手書き |
| 画像 | – | PNG / JPEG / WebP / GIF を挿入（PNG と JPEG 以外は PNG に変換） |

- 「文字を編集」で書き換えた文字は、ほかのテキストと同じく移動・幅の変更・色や太字の変更ができる。Delete で消すと元の文字に戻る。中身を空にして確定すると元の文字を消したことになる
- 選択中の書き込みは Delete で消える。色・文字サイズ・線の太さを変えると選択中の書き込みに反映される
- 元に戻す / やり直す: Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y）
- ページ移動: ◀ ▶、← →、PageUp / PageDown
- サムネイルはドラッグで並べ替え、⟲ ⟳ で回転、✕ で削除
- 「PDF を後ろに追加」か、編集中の画面へのドロップで別の PDF を末尾に結合

## 仕組み

### 文字の書き換え

PDF にはテキストボックスや段落の情報がない。中身は「このフォントで、この座標に、この文字列を描く」という命令の並びになっている。そこで次の手順で書き換える。

1. pdf.js で文字の位置を取り出し、同じ行に並ぶ文字を行に、行間がそろって縦に続く行を段落（ブロック）にまとめる。これを点線の枠で示す
2. クリックしたブロックを、同じ位置・サイズ・色・太さのテキストに置き換える。2 行以上の段落は元の幅で折り返す。色は pdf-lib でページの描画命令から読み、背景色は表示中のページから拾う
3. 保存時は、ページの描画命令から元の文字列を取り除いてから新しい文字を書き込む。後ろに続く文字の位置は変わらない。コピーや検索でも元の文字は出てこない。取り除けなかった文字（画像の中の文字など）は背景色で覆う

1 の抽出と 3 の削除は [Translation Supporter](https://github.com/symmr/ppt-translation-supporter) の `pdf-text.js` と `pdf-rewrite.js` をそのまま使っている（`lib/` にコピーしてある。直すときは元のリポジトリから取り直す）。

### 全体

- 表示は [pdf.js](https://mozilla.github.io/pdf.js/)、書き出しは [pdf-lib](https://pdf-lib.js.org/) + [@pdf-lib/fontkit](https://github.com/Hopding/fontkit)。どれも jsDelivr から読み込む
- 書き込みは PDF のユーザー座標で持つ。ページを回転・拡大しても位置がずれず、保存時にそのままページの内容として描き込む（PDF の注釈オブジェクトではない）
- テキストは Noto Sans JP（TrueType）を使った文字だけサブセット埋め込みする。保存した PDF でも文字として選択・検索できる。フォント（約 5 MB）はテキストを含む PDF を初めて保存するときに一度だけ取得する
- fontkit のサブセット出力のバグ（奇数長グリフで loca がずれる）は Translation Supporter と同じパッチで回避している

## 制限

- **白塗りは見た目を隠すだけ。** 下の文字や画像は PDF に残り、コピーや抽出で読める。機密情報の墨消しには使わないこと
- 書き換えた文字は Noto Sans JP で書く。元の PDF のフォントは使われている文字しか入っていないことが多く、そのフォントでは新しい文字を書けないため。書体が少し変わる
- 文字数が変わっても、周りの文章は詰まったり押し出されたりしない。長くなった段落は下に伸びるので、重なる場合は幅を広げるか文字を小さくする
- スキャンした PDF（文字が画像になっているもの）は「文字を編集」では書き換えられない。白塗り + テキストで上書きする
- 縦書きや斜めの文字はブロックとして拾わない
- パスワード付きの PDF は開けない
- フォームの入力欄、しおり、リンクなどの文書単位の情報は保存した PDF に引き継がれないことがある
